# DividePDF

Ferramenta simples para separar páginas de arquivos PDF diretamente no navegador.

## Acesso

Use o DividePDF em [dividepdf.vercel.app](https://dividepdf.vercel.app/).

## Uso

Abra o site, selecione um PDF e escolha entre separar uma página por arquivo ou informar intervalos de páginas. Os arquivos resultantes são baixados em um ZIP.

O processamento acontece localmente no navegador. Os documentos não são enviados para servidores.
