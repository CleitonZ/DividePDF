# DividePDF

Ferramenta simples para separar páginas de arquivos PDF diretamente no navegador.

## Uso

Abra `index.html` em um navegador moderno, selecione um PDF e escolha entre separar uma página por arquivo ou informar intervalos de páginas. Os arquivos resultantes são baixados em um ZIP.

O processamento acontece localmente no navegador. Os documentos não são enviados para servidores.

## Publicação

Este projeto é uma página estática e pode ser hospedado no GitHub Pages ou em outro serviço de hospedagem estática.
